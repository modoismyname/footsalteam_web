사용설명서
이 브라우저에서는 저장소(localStorage)를 쓸 수 없어 새로고침하면 데이터가 사라집니다. [팀 확정]으로 받은 JSON 파일과 [명단 내보내기] 파일을 보관하세요.

참석 체크

팀 구성 후 선수를 끌어서 다른 팀의 빈 슬롯이나 교체대기로 옮길 수 있습니다. 다른 선수 위에 놓으면 두 선수를 맞바꿉니다. [팀 확정]을 누르면 편집이 잠기고 JSON 파일로 저장됩니다.

선수 목록

# 이름 활동량스피드개인기협동력컨디션 합계

등록된 선수가 없습니다. 위에서 이름을 입력해 선수를 추가하세요.

능력치는 각 항목의 1·2·3을 누르면 바로 바뀌고 자동 저장됩니다. 이름을 더블클릭하거나 [수정]을 눌러 이름을 바꿀 수 있습니다. [명단 내보내기]로 받은 파일을 다른 PC에서 [명단 가져오기] 하면 선수 명단을 옮길 수 있습니다.
